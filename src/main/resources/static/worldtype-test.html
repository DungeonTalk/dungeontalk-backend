🌍 세계관 관리 API 테스트

📋 세계관 조회

GET /api/world-types

➕ 세계관 생성 (관리자)

POST /api/world-types/admin

✏️ 세계관 수정 (관리자)

PUT /api/world-types/admin/{id}

🔄 세계관 상태 토글 (관리자)

PATCH /api/world-types/admin/{id}/toggle

🗑️ 세계관 삭제 (관리자)

DELETE /api/world-types/admin/{id}

🔍 특정 세계관 조회

GET /api/world-types/{id} 또는 GET /api/world-types/code/{code}
